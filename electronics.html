NeoPixel & Desktop Turret HackPack

The two projects we had completed in the last month in class was a NeoPixel LED project and a Mark Rober "HackPack" project. These two projects were very fun and helped us understand the basics of LED wiring, assembly, and simple coding.



The NeoPixel project basically involved an LED array that we had programmed to display specific images using each of the LED lights. The two images we had programmed onto the LEDs were a flower and a smiley face.


We learned a lot throughout the process of the project, and my favorite part was being able to make my own images on the NeoPixel array because it felt like I had some creative control over it too.

The second project we did was a Mark Rober "Desktop Turret HackPack" that we assembled and used microcontrollers to program with. We made simple adjustments to the code to make the aiming more precise, and we had 3D printed a mount for a laser sight to make it even more accurate. It was a very fun project and we learned so much about Arduino software and assembly.
